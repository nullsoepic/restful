Restful
======

Save multiple respawn points and pick where you respawn when you die. Right-click beds or charged respawn anchors to add them. Default max is 5, configurable from 0-100.

Type `/restful` to manage your list - rename, favorite, reorder, or delete. When you die you get a grid of all valid beds, click or press 1-9 to pick.

Requires Minecraft 1.21.1, NeoForge 21.1.x, Java 21. Config is in `serverconfig/restful.toml`.
